# GARI -> MetaForge DEV / AAS Upstream Contract

Event: GA-GARI-MARKET-INTELLIGENCE-CONVERGENCE-001

This repository is the current software-factory substrate for MetaForge DEV until a distinct canonical MetaForge repository is established.

Atlas Automated Systems (AAS) is organizational capability, not software. AAS owns orchestration, agentic systems, automation, integrations, workflow/runtime behavior and customer implementation inside MetaForge.

## Accepted upstream objects
- APPROVED_PORTFOLIO_RECOMMENDATION
- SOLUTION_BUILD_ORDER
- STANDARD_IMPACT
- VENDOR_IMPACT
- TECHNOLOGY_CHANGE
- HARDWARE_IMPACT when software/runtime compatibility is affected

## Production chain
GARI -> JANUS approval -> Consulting where customer/problem validation is needed -> SolutionBuildOrder -> MetaForge DEV -> AAS Office -> Packet OS -> Workforce Spine -> CrownGrid -> build/integrate/orchestrate/implement -> SECA/DevOS/Medusa -> ProofGrid -> demo-ready -> sale-ready -> market feedback -> GARI.

No recommendation bypasses engineering, security, verification, deployment or commercial acceptance gates.
